Guardado y privacidad

Pascal & Sara

El juego no tiene cuentas de alumnado, analítica, anuncios ni base de datos de partidas. Usa localStorage para progreso y borradores y una cookie de preferencias limitada a la ruta del juego. GitHub recibe las solicitudes normales de alojamiento de la web.

Usa un alias. El JSON exportado contiene alias, ajustes, misiones, ayudas consultadas, recursos y código escrito. Consérvalo en un lugar propio. La importación comprueba tipo de juego, tamaño, campos y límites; no ejecuta su contenido.

Los motores se ejecutan en trabajadores. El código de práctica puede leer y escribir dentro del sistema de archivos virtual del motor. No se ejecuta como un programa nativo de tu ordenador. Los límites de tiempo, salida y tamaño ayudan a detener errores.

La ofuscación dificulta la lectura directa del código de aplicación. No oculta de forma inviolable las soluciones ni protege las calificaciones: este es un juego formativo local. Las propuestas didácticas se pueden consultar deliberadamente.

No se descargan partidas automáticamente al cerrar porque los navegadores no lo garantizan. Usa Guardar partida y verifica el archivo.
